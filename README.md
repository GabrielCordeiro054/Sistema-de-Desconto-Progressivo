# Sistema de Desconto Progressivo

## Descrição

Este projeto foi desenvolvido em Python para calcular descontos progressivos em uma loja online, de acordo com o valor total da compra.

## Regras de desconto

* Compras abaixo de R$ 200,00: **5% de desconto**
* Compras de R$ 200,00 até abaixo de R$ 300,00: **10% de desconto**
* Compras a partir de R$ 300,00: **15% de desconto**

## Funcionamento

O programa solicita ao usuário o valor total da compra, verifica qual desconto deve ser aplicado e calcula:

* O percentual de desconto;
* O valor do desconto;
* O valor total a pagar após o desconto.

## Tecnologias utilizadas

* Python
* Visual Studio Code

## Atividade

**Agenda 6 - Desenvolvimento de Sistemas I (DS I)**

O programa utiliza estruturas de decisão `if`, `elif` e `else` para implementar o sistema de desconto progressivo.
